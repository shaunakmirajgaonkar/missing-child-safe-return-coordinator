# 🛟 SafeReturn Local

Privacy-first, local-first missing-child safe-return coordination support.

## Features
- Verified/pending sighting organization
- Evidence-consistency screening
- Verification-first workflow
- Coarse search-zone prioritization
- Duplicate-report signals
- Local CSV validation and export
- No external APIs
- Synthetic demonstration data

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app.py
```

**Safety:** This is decision support for authorized responders. It is not a replacement for emergency services, police, child-protection professionals, or established missing-child procedures.
